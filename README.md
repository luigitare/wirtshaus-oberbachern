# Wirtshaus Oberbachern – Website-Entwurf

Digitale Visitenkarte für das **Wirtshaus Oberbachern** als Location für
Veranstaltungen: Hochzeiten, Familien- und Firmenfeiern, Vereinsfeste.

## Status: Design-Entwurf (Richtung 3)

- Feststehendes, großes Hintergrundfoto – beim Scrollen wechselt es weich
  vom hellen Tagesfoto in das Nachtfoto mit Kerzenlicht
- Inhalte scrollen in einzelnen „Panels" darüber, mit großen Pausen,
  in denen das Foto frei zu sehen ist
- Panels blenden sanft ein, sobald sie ins Bild rücken
- Auf Handy-Hochformat ist das Foto komplett sichtbar (weiche Unschärfe-Ränder)
- **Alle Texte sind Platzhalter** – echte Inhalte folgen, sobald das Design steht

## Ansehen

`index.html` direkt herunterladen und im Browser öffnen – alle Bilder
sind eingebettet, kein Server nötig.

Alternativ: GitHub Pages aktivieren
(Repo → Settings → Pages → Branch `main` → Save),
dann läuft die Seite unter `https://luigitare.github.io/wirtshaus-oberbachern/`.

## Feedback-Fragen

1. Farbwelt: Creme-Holz-Grün – passt das zum Haus oder eher wärmer/kühler?
2. Bildauswahl: Welches Foto soll das Eröffnungsbild (Hintergrund Tag) sein?
3. Tonalität: Wie viel Mundart darf sein („Gfeiert wird im Gwölbe")?
4. Fehlen Anlass-Kategorien (z. B. „Weihnachten im Gewölbe")?
